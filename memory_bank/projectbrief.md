# Project Brief

## Обзор проекта
Telegram бот для управления расписанием и домашними заданиями в школе.

## Цели проекта
- Управление расписанием уроков
- Управление домашними заданиями
- Управление классами
- Напоминания о заданиях

## Технологический стек
- Python (Telegram Bot API, SQLite)
- Платформа: Render (деплой)

## Project Deliverables

| ID | Название | Статус | Вес |
|----|----------|--------|-----|
| 1 | Ядро бота (main.py, обработчики) | completed | 30% |
| 2 | База данных (models, setup) | completed | 20% |
| 3 | Расписание уроков | completed | 15% |
| 4 | Домашние задания | completed | 15% |
| 5 | Управление классами | completed | 10% |
| 6 | Деплой на Render | completed | 10% |
