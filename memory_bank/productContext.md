# Product Context

## Зачем нужен проект
Школьный Telegram бот для автоматизации управления учебным процессом:
- Ученики могут быстро узнать расписание и домашние задания
- Классные руководители могут управлять расписанием
- Система напоминаний помогает не забыть о ДЗ

## Проблемы пользователей
- Нет единого источника информации о расписании
- Сложно отслеживать домашние задания по разным предметам
- Нужно вручную напоминать о дедлайнах

## Целевая аудитория
- Школьники (основные пользователи)
- Классные руководители (управление)
