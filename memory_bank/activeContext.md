# Active Context

## Текущий фокус
Проект находится в рабочем состоянии. Бот развернут на Render.

## Активные решения
- SQLite база данных для хранения данных
- aiogram 2.x для Telegram Bot API
- APScheduler для напоминаний

## Приоритеты
- Поддержание работоспособности
- Возможные улучшения функциональности
